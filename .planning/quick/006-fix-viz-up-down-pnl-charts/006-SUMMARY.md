### Task 2: Improve Summary Chart Financial Metrics
**Status:** Complete
**Commit:** 61f5c2b

Enhanced the summary chart with clearer financial narrative:

1. **Reordered subplots** for logical flow:
   - Row 1: Portfolio Value (position holdings at current prices)
   - Row 2: Net Cash (received - spent)
   - Row 3: Unrealized P&L (paper gains/losses)
   - Row 4: Realized P&L + Total P&L (locked gains + total performance)

2. **Improved Net Cash display** (subplot 2):
   - Primary line: Net Cash (dark blue, bold 2.5px width)
   - Context lines: Cash Spent and Cash Received (dotted, lighter, 50% opacity)
   - Zero line for reference

3. **Added Total P&L** (subplot 4):
   - Shows realized + unrealized combined
   - Dark green, bold 2px width
   - Gives complete picture of trading success

4. **Better subplot organization**:
   - Moved max unrealized envelope to subplot 3 (with unrealized P&L)
   - Updated all subplot titles for clarity
   - Updated y-axis labels to match new order

**Files modified:**
- `src/tools/visualize_portfolio.py`: Updated `create_summary_chart()` function

**Verification:** Ran tool on test session, confirmed 4 clear panels with improved layout.

### Task 3: Make Hourly Charts Default Behavior
**Status:** Complete
**Commit:** 0fa9062

Changed the flag behavior to make hourly charts the default:

1. **Changed flag**: `--hourly` (opt-in) → `--no-hourly` (opt-out)
2. **Updated help text**: "Skip per-hour charts (default: generate hourly charts)"
3. **Updated condition**: `if args.hourly:` → `if not args.no_hourly:`

**Benefits:**
- Better default UX (most users want detailed per-market charts)
- Faster workflow (no need to remember --hourly flag)
- Still allows skipping hourly charts when needed

**Files modified:**
- `src/tools/visualize_portfolio.py`: Updated argument parser and chart generation logic

**Verification:**
- Default behavior: Generates both summary AND hourly charts
- With --no-hourly: Generates only summary chart
