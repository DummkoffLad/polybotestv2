# Phase 07.1 Plan 06: Extract Shared PnL Calculator Summary

**One-liner:** Unified PnL calculation in src/analysis/pnl_calculator.py, eliminating 15 lines of duplicated logic across 3 strategies.

## Objective

Extract the duplicated PnL calculation logic from strategies into a single shared module to prevent bugs and ensure consistency.

## What Was Built

### New Module: src/analysis/pnl_calculator.py

Created centralized PnL calculator with:
- `calculate_strategy_pnl(portfolio, final_prices)` function
- Calculates realized + unrealized PnL from portfolio state
- Handles edge cases: missing prices, zero shares, empty portfolios
- Documented with docstring and usage example

### Updated Strategies

Refactored 3 representative strategies to delegate to shared calculator:

**profit_taker strategy:**
```python
# Before (4 lines):

return self.portfolio.realized_pnl, unrealized
```

## Decisions Made

### 1. Location: src/analysis/pnl_calculator.py

**Why analysis module?**
- PnL is a metrics/analysis concern, not strategy logic
- Already have src/analysis/ for reports, attribution, equity tracking
- Natural fit with existing module organization

**Why not src/strategies/utils.py?**
- Would couple all strategies to strategy module
- PnL calculation is independent of strategy behavior

### 2. Function Signature

**Choice:**
```python
def calculate_strategy_pnl(
    portfolio: Portfolio,
    final_prices: Dict[str, PriceSnapshot]
) -> Tuple[Decimal, Decimal]:
```

**Rationale:**
- Takes portfolio and prices (no strategy coupling)
- Returns tuple for consistency with existing interface
- Clean separation of concerns

### 3. Edge Case Handling

Built-in handling for:
- Token not in final_prices → ignored (no value)
- Price is None or 0 → ignored (no valid price)
- Empty portfolio → returns (realized_pnl, 0)
