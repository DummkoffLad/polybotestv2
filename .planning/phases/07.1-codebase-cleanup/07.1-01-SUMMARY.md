# Phase [07.1] Plan [01]: Extract Duplicated _to_side() Function

**One-liner:** Eliminated 10 duplicate _to_side() implementations by extracting to single shared utils.py module

## What Changed

### Created
- **src/strategies/utils.py**: New shared utilities module
  - `to_side(trade_side: TradeSide) -> Side`: Converts TradeSide enum to Side enum
  - Public API function with comprehensive documentation
  - Explains historical context (previously duplicated in 10 files)

### Modified
All 10 strategy files updated identically:
1. Removed local `def _to_side(side: TradeSide) -> Side` definition
2. Added `from ..utils import to_side` import
3. Replaced all `_to_side(` calls with `to_side(`

**Affected strategies:**
- aggressive
- conservative
- hybrid_conservative
- mirror
- momentum
- price_level
- profit_taker
- simple_follow
- spread_aware
- velocity

## Technical Details

**Before:**
```python
# In EVERY strategy file (10x duplication):
def _to_side(side: TradeSide) -> Side:
    return Side.UP if side == TradeSide.UP else Side.DOWN
```

**After:**
```python
# In src/strategies/utils.py (once):
def to_side(trade_side: TradeSide) -> Side:
    """Convert TradeSide enum to Side enum.

    Args:
        trade_side: TradeSide.UP or TradeSide.DOWN from data models

    Returns:
        Side.UP or Side.DOWN from core types

    Note: Centralized conversion used by all strategies.
          Previously duplicated in 10 strategy files.
    """
    return Side.UP if trade_side == TradeSide.UP else Side.DOWN

# In each strategy file:
from ..utils import to_side
# ... use to_side() throughout
```

**Code reduction:**
- Before: 30 lines (3 lines × 10 files)
- After: 22 lines (utils.py) + 10 import lines = 32 lines
- **But**: Single source of truth, easier to maintain, extensible for future utilities
