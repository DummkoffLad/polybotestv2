## Technical Notes

### Mixin Initialization Pattern

```python
class ConservativeMirrorStrategy(SkipHelperMixin, HourlyBudgetMixin, Strategy):
    def __init__(self):
        SkipHelperMixin.__init__(self)  # Initialize skip tracking
        HourlyBudgetMixin.__init__(self)  # Initialize hourly budget
        # ... rest of strategy init

    def initialize(self, config):
        SkipHelperMixin.__init__(self)  # Re-init for reset
        HourlyBudgetMixin.__init__(self)  # Re-init for reset
        self._current_hour = datetime.now(timezone.utc).hour
        # ... rest of initialize
```

**Why explicit init?**
- Avoids complex MRO (Method Resolution Order) chains
- Makes initialization order explicit and debuggable
- Each mixin manages its own state independently

### simple_follow Exception

simple_follow only uses SkipHelperMixin because it doesn't use hourly budget tracking:
- Uses fixed position sizing ($1-7 per trade)
- No hourly spend limits
- Simpler design doesn't need budget resets
