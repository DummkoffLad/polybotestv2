## Decisions Made

**Package structure approach:**
- models.py first (no dependencies)
- loader.py next (depends on models)
- processor.py next (depends on models, uses strategy)
- replayer.py last (orchestrates loader + processor)
- Rationale: Dependency order makes imports clean and circular dependency impossible

**Property delegation for session_id:**
- SessionReplayer.session_id exposed as property
- Delegates to self.loader.session_id
- Rationale: Maintains backward compatibility with comparator.py expecting replayer.session_id

**Slightly over 300 lines for loader.py:**
- loader.py is 314 lines (target was <300)
- Accepted because: complex parsing logic with multiple formats (type-based, log-based, price snapshots)
- Alternative would split parsing into sub-functions reducing readability
- Rationale: 314 is close enough and code is well-structured
