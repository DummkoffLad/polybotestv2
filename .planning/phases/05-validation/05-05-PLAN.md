  <name>Task 1: Build ValidationPipeline orchestrator</name>
  <files>src/validation/pipeline.py, src/validation/__init__.py</files>
  <action>
    Create src/validation/pipeline.py with the ValidationPipeline class that orchestrates the full validation workflow:

    ValidationPipeline class:
    - __init__(session_dir: Path = Path("data/sessions"), output_dir: Path = Path("data/validation"), strategy_name: str = "mirror")
    - data_split: DataSplitManager (initialized internally)
    - sweeper: SensitivitySweeper (initialized with baseline params from Phase 3+4)
    - latency_sim: LatencySimulator (initialized with baseline config)
    - report_gen: ValidationReportGenerator (initialized with output_dir)

    Pipeline methods:
    - setup_data_split(in_sample_ids: List[str], out_of_sample_ids: List[str]) -> None
      Configures which sessions are in-sample vs out-of-sample.
      Default in-sample: ["session_20260130_032713"] (Phase 1 baseline session).

    - run_out_of_sample(strategy_name: str = "mirror") -> List[Decimal]
      For each out-of-sample session:
        1. Create SimpleOptimizer with session path
        2. Run strategy replay (simulate_resolution=True)
        3. Collect total_pnl (or resolved_pnl if available)
      Returns list of session PnLs.

    - run_sensitivity(session_path: Path) -> SensitivityResult
      1. Get baseline params from BASELINE_PARAMS dict (all Phase 3+4 tunable params)
      2. Create SensitivitySweeper with baseline params
      3. For each one-at-a-time config variant:
         a. Run replay with config overrides via SimpleOptimizer
         b. Collect PnL
      4. Assess robustness and return SensitivityResult

    - run_latency_analysis(session_path: Path) -> List[LatencyImpactResult]
      For each scenario (zero, baseline, stress_2x, stress_3x):
        1. Run replay with zero latency to get baseline PnL
        2. For latency scenarios: replay each trade, apply price degradation
           to the execution price using LatencySimulator.apply_price_degradation()
        3. Compute degradation as difference from zero-latency PnL
      Returns list of LatencyImpactResult per scenario.

    - run_full_validation() -> ValidationSummary
      Orchestrates the complete pipeline:
        1. run_out_of_sample() -> get session PnLs
        2. Use KellyValidator.bootstrap_confidence_interval() for CI
        3. run_sensitivity() on first out-of-sample session (representative)
        4. run_latency_analysis() on first out-of-sample session
        5. Aggregate into ValidationSummary
        6. Generate and save report
        7. Print console summary
      Returns the full ValidationSummary.

    - run_validation() module-level convenience function:
      Quick entry point: run_validation(out_of_sample_sessions=["session_xxx", ...])

    BASELINE_PARAMS dict (all Phase 3+4 tunable parameters with their optimized values):
