<feature>
  <name>ValidationReportGenerator</name>
  <files>src/validation/report.py, tests/unit/test_validation_report.py</files>
  <behavior>
    ValidationReportGenerator produces go/no-go reports for live trading readiness.

    GoNoGoDecision dataclass:
    - decision: bool (True = GO, False = NO-GO)
    - criteria_results: Dict[str, bool] (each criterion name -> pass/fail)
    - rationale: str (human-readable explanation for each criterion)
    - overall_confidence: str ("high", "medium", "low" based on number of sessions)

    Go/no-go criteria (ALL must pass for GO):
    1. positive_mean_pnl: mean PnL on out-of-sample data > 0
    2. acceptable_downside: 95% CI lower bound > -$5
    3. no_critical_fragile: no fragile parameters in critical set (kelly_fraction, quality_threshold)
    4. acceptable_latency: latency PnL degradation < 15%

    ValidationSummary dataclass:
    - oos_sessions_tested: int
    - oos_mean_pnl: Decimal
    - oos_ci_lower: float
    - oos_ci_upper: float
    - oos_positive_sessions: int
    - param_variants_tested: int
    - params_fragile: List[str]
    - params_robust: List[str]
    - latency_degradation_pct: float
    - decision: GoNoGoDecision

    ValidationReportGenerator class:
    - __init__(output_dir: Path = Path("data/validation"))
    - decide_go_nogo(summary: ValidationSummary) -> GoNoGoDecision
    - generate_console_summary(summary: ValidationSummary) -> str (concise, for terminal)
    - generate_markdown_report(summary: ValidationSummary) -> str (detailed, for saving)
    - save_report(summary: ValidationSummary, filename: str = None) -> Path (saves markdown to output_dir)

    Console summary format:
    ```
    ============================================================
    VALIDATION REPORT: GO / NO-GO
    ============================================================
    Decision: GO (or NO-GO)
    Confidence: high/medium/low (based on session count)

    Out-of-Sample: N sessions, mean PnL $X.XX, 95% CI [$X.XX, $X.XX]
    Sensitivity: N params tested, M fragile
    Latency: X.X% degradation (baseline 3.5s)

    Criteria:
      [PASS/FAIL] Positive mean PnL
      [PASS/FAIL] Acceptable downside (CI > -$5)
      [PASS/FAIL] No critical fragile params
      [PASS/FAIL] Latency impact < 15%
    ============================================================
    ```

    Markdown report includes additional sections:
    - Executive summary with decision
    - Out-of-sample performance table (per-session PnL breakdown)
    - Parameter sensitivity heatmap (text-based)
    - Latency impact analysis (baseline vs stress scenarios)
    - Detailed criteria assessment
    - Recommendations for improvement (if NO-GO)

    Test cases:
    - All criteria pass -> GO decision
    - Negative mean PnL -> NO-GO with correct rationale
    - CI lower < -$5 -> NO-GO with correct rationale
    - Fragile critical param -> NO-GO with correct rationale
    - Latency > 15% -> NO-GO with correct rationale
    - Multiple failures -> NO-GO with all failures listed
    - 1 session -> "low" confidence
    - 3-4 sessions -> "medium" confidence
    - 5+ sessions -> "high" confidence
    - Console summary is under 20 lines
    - Markdown report includes all required sections
    - save_report creates file at expected path
  </behavior>
  <implementation>
    Create src/validation/report.py with GoNoGoDecision, ValidationSummary, ValidationReportGenerator.
    Decision logic is pure function on ValidationSummary -- no side effects, fully testable.
    Reuse KellyValidator from Phase 4 for any statistical calculations needed.
    Console output uses simple text formatting (no dependencies).
    Markdown output uses standard markdown syntax.
    save_report creates output_dir if not exists, writes timestamped markdown file.
    Confidence level based on session count: 1-2 = low, 3-4 = medium, 5+ = high.
  </implementation>
</feature>
