<objective>
Build the DataSplitManager that tracks which recorded sessions are in-sample (used for Phase 1-4 optimization) vs out-of-sample (reserved for Phase 5 validation). This prevents data leakage -- the most critical anti-pattern in strategy validation.

Purpose: Without clean data provenance, validation results are meaningless. If an in-sample session accidentally enters validation, the go/no-go decision is unreliable.
Output: Working DataSplitManager with TDD tests proving leakage prevention.
</objective>

<feature>
  <name>DataSplitManager</name>
  <files>src/validation/__init__.py, src/validation/data_split.py, tests/unit/test_data_split.py</files>
  <behavior>
    DataSplitManager tracks session provenance (in-sample vs out-of-sample).

    Core behaviors:
    - mark_in_sample(session_id) -> registers session as used for optimization
    - mark_out_of_sample(session_id) -> registers session for validation only
    - mark_out_of_sample(session_id) raises ValueError if session_id is already in-sample (leakage prevention)
    - get_validation_sessions() -> returns list of Paths to out-of-sample session files
    - get_in_sample_sessions() -> returns list of in-sample session IDs
    - is_in_sample(session_id) -> bool check
    - is_out_of_sample(session_id) -> bool check
    - save()/load() -> persist split metadata to JSON file for reproducibility
    - validate_no_leakage(session_ids) -> raises if any session_id is in-sample

    Known in-sample sessions (from Phase 1 context):
    - session_20260130_032713 (used for Phase 1 baselines and Phase 2-4 optimization)

    Test cases:
    - mark_in_sample then mark_out_of_sample same ID -> ValueError
    - mark_out_of_sample then get_validation_sessions returns correct paths
    - save/load roundtrip preserves all session classifications
    - validate_no_leakage with mixed sessions -> raises for in-sample ones
    - empty manager returns empty lists
    - session discovery from data/sessions/ directory

    Implementation notes:
    - Use sets for O(1) membership testing
    - Store metadata as JSON in data/validation/split_metadata.json
    - Use pathlib.Path for cross-platform compatibility
    - Keep session_id as string (filename stem without .jsonl extension)
  </behavior>

    Session discovery: scan data/sessions/*.jsonl for available sessions.
  </implementation>
</feature>
