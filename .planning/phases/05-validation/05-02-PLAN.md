<feature>
  <name>SensitivitySweeper</name>
  <files>src/validation/sensitivity.py, tests/unit/test_sensitivity.py</files>
  <behavior>
    SensitivitySweeper tests parameter robustness using one-at-a-time and grid sweeps.

    Parameters to sweep (all from Phases 3 and 4):
    - kelly_fraction: 0.5 (half Kelly)
    - quality_threshold: 0.40
    - soft_floor: 0.85
    - hard_floor_drawdown: 0.30
    - per_market_cap_pct: 30
    - cash_reserve_pct: 10
    - conviction_position_weight: 0.60
    - conviction_scale_in_weight: 0.25
    - conviction_entry_speed_weight: 0.15
    - dca_quality_threshold: 0.75
    - correlation_penalty: 0.15
    - rebalancing_edge_gap: 1.5
    - rolling_window_size: 50
    - min_trades_for_kelly: 20
    - max_position_cap: 0.20

    Core behaviors:
    - SensitivitySweeper(baseline_params, sweep_range=0.15) -> creates sweeper
    - generate_variants(param_name, param_value) -> [low, baseline, high] values
    - one_at_a_time_sweep() -> list of (param_name, value, config_dict) tuples
    - full_grid_sweep(param_subset) -> list of config_dicts for 2-3 interacting params
    - assess_robustness(results) -> list of fragile parameter names
    - A parameter is "fragile" if +-15% change causes >30% PnL swing from baseline

    ParamSweepResult dataclass:
    - param_name: str
    - values_tested: List[float] (low, baseline, high)
    - pnl_results: List[Decimal] (corresponding PnL for each value)
    - baseline_pnl: Decimal
    - max_swing_pct: float (max percentage swing from baseline)
    - is_fragile: bool (max_swing_pct > 0.30)

    SensitivityResult dataclass:
    - param_results: List[ParamSweepResult]
    - total_configs_tested: int
    - fragile_params: List[str]
    - robust_params: List[str]

    Test cases:
    - generate_variants(0.5, 0.15) -> [0.425, 0.5, 0.575]
    - generate_variants(100, 0.15) -> [85, 100, 115]
    - one_at_a_time_sweep with 3 params -> 9 configs (3 values x 3 params)
    - non-numeric param is skipped
    - assess_robustness with >30% swing -> marks as fragile
    - assess_robustness with <30% swing -> marks as robust
    - full_grid_sweep with 2 params -> 9 configs (3x3)
    - edge case: baseline_pnl == 0 -> handle division by zero gracefully
  </behavior>
  <implementation>
    Create src/validation/sensitivity.py with SensitivitySweeper class.
    Use dataclasses for ParamSweepResult and SensitivityResult.
    generate_variants uses simple multiplication: [val * (1 - range), val, val * (1 + range)].
    one_at_a_time_sweep yields configs varying one param while keeping others at baseline.
    assess_robustness computes max(|pnl_low - pnl_base|, |pnl_high - pnl_base|) / |pnl_base|.
    full_grid_sweep uses itertools.product for specified param subset only.
    The sweeper generates configs but does NOT run replays itself -- the pipeline (Plan 05) handles execution. This keeps the sweeper testable without needing session data.
  </implementation>
</feature>
