**src/analysis/attribution.py:**
Create `AttributedTrade` dataclass with fields:
- Entry: entry_timestamp (datetime), market_id (str), token_id (str), side (str: "UP"/"DOWN"), action (str: "BUY"/"SELL"), entry_shares (Decimal), entry_price (Decimal), entry_cost (Decimal)
- Exit: exit_timestamp (Optional[datetime]), exit_shares (Optional[Decimal]), exit_price (Optional[Decimal]), exit_proceeds (Optional[Decimal])
- Outcome: status (str: "open"/"win"/"loss"/"breakeven"/"resolved"), realized_pnl (Decimal), unrealized_pnl (Decimal)
- Leader comparison: leader_dollars (Decimal), leader_price (Decimal)
- Strategy tag: strategy_name (str) — which strategy generated this trade

Methods:
- `close_trade(timestamp, shares, price)` — Mark as closed, calculate realized PnL. For BUY: pnl = proceeds - cost. For SELL: pnl = cost - proceeds. Set status to win/loss/breakeven.
- `update_unrealized(current_price)` — Update unrealized PnL for open positions. unrealized = (shares * current_price) - entry_cost.
- `to_dict()` — Serialize to dict for JSONL persistence (convert Decimal to str, datetime to isoformat)

Create `TradeAttributor` class:
- `__init__()` — Initialize trades dict (token_id -> list of AttributedTrade, since same token can have multiple entries)
- `record_entry(event: MarketEvent, decision: TradeDecision, strategy_name: str) -> str` — Create AttributedTrade from event + decision, store by token_id, return trade_id (f"{token_id}_{sequence}")
- `record_exit(token_id: str, timestamp, shares, price)` — Find open trade for token_id, close it. If partial exit, handle proportionally.
- `update_all_unrealized(current_prices: Dict[str, Decimal])` — Mark-to-market all open trades
- `get_summary() -> dict` — Return: total_trades, wins, losses, open, win_rate, total_realized_pnl, avg_win, avg_loss, best_trade (max realized_pnl), worst_trade (min realized_pnl), total_unrealized_pnl
- `get_all_trades() -> List[AttributedTrade]` — Flat list of all trades

IMPORTANT: Use Decimal exclusively for money. Never use float for financial calculations. Use .quantize(Decimal("0.0001")) for price precision matching Portfolio convention.

**src/analysis/equity_tracker.py:**

Create `EquitySnapshot` dataclass:
- timestamp (datetime)
- realized_pnl (Decimal)
- unrealized_pnl (Decimal)
- total_equity (Decimal) — starting_capital + realized + unrealized
- open_positions (int)
- deployed_capital (Decimal)
- trade_count (int) — cumulative trades so far

Create `EquityTracker` class:
- `__init__(starting_capital: Decimal)` — Store starting capital, initialize empty snapshots list
- `record_snapshot(timestamp: datetime, portfolio: Portfolio, current_prices: Dict[str, Decimal])` — Call portfolio.calculate_pnl(current_prices) to get realized + unrealized. Create EquitySnapshot with total_equity = starting_capital + realized + unrealized. Append to snapshots list.
- `record_manual_snapshot(timestamp: datetime, realized_pnl: Decimal, unrealized_pnl: Decimal, open_positions: int, deployed_capital: Decimal, trade_count: int)` — For when caller computes values directly (used in replay integration where portfolio state comes from strategy).
- `to_dataframe() -> pd.DataFrame` — Convert snapshots to pandas DataFrame with columns: equity, realized_pnl, unrealized_pnl, open_positions, deployed_capital. Index = timestamp. Use lazy import for pandas (import inside method).
- `get_final_equity() -> Decimal` — Return last snapshot's total_equity, or starting_capital if empty
- `get_return_pct() -> Decimal` — (final_equity - starting_capital) / starting_capital * 100

IMPORTANT: Pandas is only imported inside to_dataframe(). The core EquityTracker works without pandas installed. This keeps the module lightweight for runtime use.

Use make_portfolio() helper to create Portfolio with preset positions for testing record_snapshot().
