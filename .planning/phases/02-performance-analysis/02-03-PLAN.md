**Modify src/framework/replay.py:**

Add a new method to SessionReplayer and modify the `run()` method to optionally include full analysis.

1. Add new parameter to `run()`: `track_analysis: bool = False`
   When True, the replay creates and populates:
   - TradeAttributor (records entries/exits)
   - EquityTracker (records snapshots after each trade)
   - SlippageAnalyzer (measures per-trade slippage)
   - Lists for sizing gaps and selection gaps

2. Inside the event loop (after existing logic), when `track_analysis=True`:
   - On BUY/SELL fill: Call `attributor.record_entry(event, decision, strategy.name)`
   - On BUY/SELL fill: Call `slippage_analyzer.measure_trade_slippage(our_price, leader_price, market_mid, action, dollars, token_id)` and collect measurement
   - On BUY/SELL fill: Call `slippage_analyzer.measure_sizing_gap(leader_dollars, our_dollars, leader_capital, our_capital, token_id)` and collect gap
   - On SKIP: Call `slippage_analyzer.record_skipped_trade(token_id, leader_action, leader_dollars, leader_price, skip_reason)` and collect gap
   - After each event (trade or skip): Record equity snapshot via `equity_tracker.record_manual_snapshot()` using strategy state (realized_pnl from strategy.calculate_pnl(), unrealized from current prices, etc.)

3. On SELL fills: Also call `attributor.record_exit(token_id, timestamp, shares, price)` to close the matching BUY trade.

4. After the event loop completes:
   - Call `attributor.update_all_unrealized(current_prices_as_decimal_dict)` for remaining open positions
   - Build equity DataFrame from tracker
   - Run DrawdownAnalyzer on equity DataFrame
   - Aggregate slippage, sizing, selection stats

5. Add new fields to ReplayResult:
   - `analysis: Optional[Dict[str, Any]]` — Contains all analysis results when track_analysis=True
   - Structure: `{"trade_summary": {...}, "drawdown": {...}, "slippage": {...}, "sizing": {...}, "selection": {...}, "equity_df": DataFrame, "attributed_trades": [...]}`

6. Add a new convenience function `run_session_replay_with_analysis()`:
   - Takes session_path, strategy, output_dir
   - Runs replay with track_analysis=True
   - Creates ReportGenerator
   - Prints console summary
   - Generates charts
   - Saves JSON report
   - Returns ReplayResult

IMPORTANT: The existing `run()` behavior MUST NOT change when `track_analysis=False` (the default). All existing tests must continue to pass. The analysis is purely additive.

Get starting_capital from strategy config: `Decimal(str(config.get('scaling', {}).get('our_capital', '100')))` (already available in _merge_config).

For leader_capital, use: `Decimal(str(config.get('scaling', {}).get('leader_estimated_capital', '900')))`

For current prices used in equity snapshots, build a Dict[str, Decimal] from self.final_prices (use mid or bid price).
