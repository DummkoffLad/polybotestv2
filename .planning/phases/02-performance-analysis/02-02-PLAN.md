**src/analysis/drawdown.py:**

Create `DrawdownAnalyzer` class:
- `analyze(equity_df: pd.DataFrame) -> dict` — Main analysis method. Expects DataFrame with 'equity' column and datetime index.
  - Calculate running peak: `peak = equity_df['equity'].cummax()`
  - Calculate drawdown series: `drawdown = (equity_df['equity'] - peak) / peak`
  - Find max drawdown (most negative value) and its timestamp
  - Find the peak before max drawdown (start of drawdown period)
  - Calculate duration from peak to trough in minutes
  - Calculate recovery: find first point after trough where equity >= peak_at_trough. If found, compute recovery time in minutes. If not recovered, return None.
  - Return dict with keys:
    - max_drawdown_pct (float, negative): Maximum percentage drawdown
    - max_drawdown_value (float): Dollar amount of max drawdown
    - drawdown_start (datetime): When peak occurred before drawdown
    - drawdown_bottom (datetime): Timestamp of lowest point
    - drawdown_duration_min (float): Minutes from peak to trough
    - recovery_time_min (Optional[float]): Minutes from trough to recovery, None if not recovered
    - current_drawdown_pct (float): Current drawdown from last peak (shows if still in drawdown)

  - Handle edge cases:
    - Single-row DataFrame: return all zeros, no drawdown
    - Monotonically increasing equity: max_drawdown_pct = 0
    - All same equity: max_drawdown_pct = 0
    - Empty DataFrame: raise ValueError("Empty equity DataFrame")

- `get_drawdown_series(equity_df: pd.DataFrame) -> pd.Series` — Return the full drawdown series (percentage from peak at each point). Used by chart generator.

**src/analysis/slippage.py:**

Create `SlippageMeasurement` dataclass:
- token_id (str)
- action (str): "BUY" or "SELL"
- leader_price (Decimal): What leader paid
- our_price (Decimal): What we paid
- market_price_at_signal (Decimal): Mid price when we detected the signal
- execution_slippage_bps (Decimal): Our price vs leader price in basis points
- delay_slippage_bps (Decimal): Market price at signal vs our price
- total_slippage_bps (Decimal): Sum of execution + delay
- trade_size_dollars (Decimal): Our trade size
- slippage_cost_dollars (Decimal): Dollar impact of slippage

Create `SizingGap` dataclass (for sizing gap analysis):
- token_id (str)
- leader_dollars (Decimal)
- our_dollars (Decimal)
- leader_pct_of_capital (Decimal): leader_dollars / leader_capital
- our_pct_of_capital (Decimal): our_dollars / our_capital
- sizing_ratio (Decimal): our_pct / leader_pct (1.0 = proportional, <1 = undersized, >1 = oversized)

Create `SelectionGap` dataclass (for skipped trade analysis):
- token_id (str)
- leader_action (str)
- leader_dollars (Decimal)
- leader_price (Decimal)
- skip_reason (str)
- eventual_pnl (Optional[Decimal]): PnL leader earned on this trade (if known, else None)

Create `SlippageAnalyzer` class:
- `measure_trade_slippage(our_price: Decimal, leader_price: Decimal, market_mid: Decimal, action: str, trade_size: Decimal, token_id: str) -> SlippageMeasurement`
  - For BUY: higher price = worse. exec_slip = (our - leader) / leader * 10000
  - For SELL: lower price = worse. exec_slip = (leader - our) / leader * 10000
  - Delay: for BUY: (our - market_mid) / market_mid * 10000
  - Total = exec + delay
  - Cost in dollars = (total_slip / 10000) * trade_size
  - All calculations in Decimal with .quantize(Decimal("0.01")) for bps

- `measure_sizing_gap(leader_dollars: Decimal, our_dollars: Decimal, leader_capital: Decimal, our_capital: Decimal, token_id: str) -> SizingGap`
  - Calculate proportional allocation for each
  - sizing_ratio = our_pct / leader_pct (handle division by zero)

- `record_skipped_trade(token_id: str, leader_action: str, leader_dollars: Decimal, leader_price: Decimal, skip_reason: str) -> SelectionGap`
  - Create SelectionGap record (eventual_pnl filled later when market resolves)

- `aggregate_slippage(measurements: List[SlippageMeasurement]) -> dict`
  - Volume-weighted average slippage (VWAP approach)
  - Total slippage cost in dollars
  - Breakdown: avg execution slippage bps, avg delay slippage bps
  - Count of trades, total volume
  - Handle empty list: return zeros

- `aggregate_sizing(gaps: List[SizingGap]) -> dict`
  - Average sizing ratio
  - Count of undersized (ratio < 0.8) vs oversized (ratio > 1.2) vs proportional
  - Total dollar difference

- `aggregate_selection(gaps: List[SelectionGap]) -> dict`
  - Count of skipped trades
  - Breakdown by skip_reason
  - Total missed PnL (from trades with known eventual_pnl)

All money calculations use Decimal. Basis point calculations use Decimal with quantize.
