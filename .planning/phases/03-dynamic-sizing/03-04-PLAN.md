  <name>Task 1: Integrate dynamic sizing into MirrorStrategy</name>
  <files>src/strategies/mirror/strategy.py, src/core/__init__.py</files>
  <action>
    Modify MirrorStrategy to use DynamicSizer, CapitalManager, and TradeQualityScorer. This is a MODIFICATION of the existing class, not a new subclass. The changes are:

    **In initialize():**
    - Import and create SizingConfig, DynamicSizer, CapitalManager, TradeQualityScorer, SelectiveFollower
    - Initialize all with starting_capital from config
    - Store as self.sizer, self.capital_manager, self.quality_scorer, self.selective_follower
    - Keep ALL existing initialization (portfolio, leader_tracker, scale_ratio, etc.)

    **In _buy():**
    Replace the existing cap logic with dynamic sizing. The flow becomes:
    1. Calculate current_equity = self._calculate_current_equity() (new helper method)
    2. Update high-water mark on both sizer and capital_manager
    3. Calculate spread_bps from prices (ask - bid) / mid * 10000. If no bid, use Decimal("500") penalty.
    4. Calculate quality_score = self.quality_scorer.score_trade(spread_bps, trade.dollars)
    5. Check quality filter: if not self.quality_scorer.should_take_trade(quality_score): return self._skip("low_quality")
    6. Check floor status: mode = self.capital_manager.check_floor_status(current_equity)
    7. Check entry permission: can_enter, reason = self.capital_manager.can_enter_new_trade(quality_score). If not can_enter: return self._skip(reason)
    8. Check position limit: can_open, reason = self.selective_follower.can_open_position(len(self.portfolio.get_positions())). If not can_open: return self._skip(reason)
    9. Calculate dynamic size: dynamic_dollars = self.sizer.calculate_position_size(current_equity, quality_score)
    10. KEEP the existing cost check (drift + spread + slippage vs max_total_cost_pct)
    11. Replace FIXED cap calculations with DYNAMIC caps:
        - deployable = current_equity * (1 - cfg.cash_reserve_pct / 100) -- uses CURRENT equity
        - mkt_cap = current_equity * cfg.per_market_cap_pct / 100 -- uses CURRENT equity
        - side_cap = current_equity * cfg.per_side_pct / 100 -- uses CURRENT equity
        - global_cap = current_equity * cfg.global_exposure_pct / 100 -- uses CURRENT equity
    12. dollars = min(dynamic_dollars, available, budget_room, mkt_room, side_room, global_room)
    13. Keep existing 5-share minimum logic
    14. Keep existing order constraint validation

    **In _sell():**
    - Add check: if not self.capital_manager.can_manage_positions(): return self._skip("hard_floor_no_management")
    - Keep ALL existing sell logic (position check, price check, loss protection, share calculation, min shares)

    **In on_fill():**
    - After existing logic, add: if decision.action == DecisionAction.SELL and we can estimate PnL from the position, call self.sizer.update_after_trade(pnl_estimate). Use a simple heuristic: if the sell price > avg_price, pnl is positive, else negative.
    - After buys AND sells, update HWM: self.capital_manager.update_high_water_mark(self._calculate_current_equity()) and self.sizer.update_high_water_mark(self._calculate_current_equity())

    **New helper _calculate_current_equity():**
    - realized = self.portfolio.realized_pnl
    - deployed = self.portfolio.get_total_deployed()
    - cash = self.config.starting_capital - deployed + realized
    - return cash + deployed  (this simplifies to starting_capital + realized_pnl)

    **Update src/core/__init__.py:**
    - Add imports for DynamicSizer, SizingConfig from .sizing
    - Add imports for CapitalManager, TradingMode from .capital_manager
    - Add imports for TradeQualityScorer, SelectiveFollower from .trade_filter

    **CRITICAL: Do NOT break existing behavior patterns:**
    - Keep the 1.30x conviction boost (line ~93 of current strategy)
    - Keep cost check before capacity checks
    - Keep hourly budget tracking
    - Keep leader_tracker updates in on_fill
    - Keep the _skip() method and skip_reasons tracking
    - Keep extreme price handling
    - All existing skip reasons must still work (no_price, cost_too_high, min_shares, etc.)
    - New skip reasons added: low_quality, soft_floor_low_quality, hard_floor_hit, hard_floor_no_management, max_positions_reached

    **IMPORTANT: The scale_ratio calculation and 1.30x boost are KEPT as-is. They still produce `our_dollars` which represents the leader-scaled target. The DynamicSizer then produces `dynamic_dollars` independently from current_equity. The final size is min(dynamic_dollars, cap_rooms...). This means dynamic sizing provides a FLOOR for quality trades and a CAP for capital protection -- it doesn't replace the leader scaling, it augments it.**
