<feature>
  <name>CapitalManager - Two-Tier Floor System</name>
  <files>src/core/capital_manager.py, tests/unit/test_capital_manager.py</files>
  <behavior>
    TradingMode is an Enum with values: NORMAL, SOFT_FLOOR, HARD_FLOOR

    CapitalManager has:
    - __init__(soft_floor_pct: Decimal = Decimal("90.0"), hard_floor_pct: Decimal = Decimal("70.0"), exceptional_quality_threshold: Decimal = Decimal("0.85"))
      - soft_floor_pct: equity as % of HWM below which soft floor activates (90% = 10% drawdown)
      - hard_floor_pct: equity as % of HWM below which hard floor activates (70% = 30% drawdown)
      - exceptional_quality_threshold: minimum quality score for trades at soft floor
    - initialize(starting_capital: Decimal) -- sets high_water_mark = starting_capital, mode = NORMAL
    - update_high_water_mark(current_equity: Decimal) -- update if current > HWM
    - check_floor_status(current_equity: Decimal) -> TradingMode
      - equity_pct = (current_equity / high_water_mark) * 100
      - If equity_pct <= hard_floor_pct: HARD_FLOOR
      - Elif equity_pct <= soft_floor_pct: SOFT_FLOOR
      - Else: NORMAL
      - Stores mode internally for can_enter/can_manage checks
    - can_enter_new_trade(quality_score: Decimal) -> tuple[bool, Optional[str]]
      - HARD_FLOOR: (False, "hard_floor_hit")
      - SOFT_FLOOR and quality < exceptional: (False, "soft_floor_low_quality")
      - SOFT_FLOOR and quality >= exceptional: (True, None)
      - NORMAL: (True, None)
    - can_manage_positions() -> bool
      - HARD_FLOOR: False (no adjustments allowed)
      - SOFT_FLOOR: True (can manage existing positions)
      - NORMAL: True
    - Property: mode -> TradingMode (current mode)
    - Property: high_water_mark -> Decimal

    Test cases:
    - Initialize $100 -> mode NORMAL, HWM $100
    - Check $95 equity (5% DD) -> NORMAL (above 90%)
    - Check $90 equity (10% DD) -> SOFT_FLOOR (at 90% threshold)
    - Check $89 equity (11% DD) -> SOFT_FLOOR
    - Check $70 equity (30% DD) -> HARD_FLOOR (at 70% threshold)
    - Check $69 equity (31% DD) -> HARD_FLOOR
    - Recovery: $70 -> HARD_FLOOR, then $91 -> NORMAL (above soft floor)
    - HWM tracking: $100 -> $120 (HWM=120) -> $108 (90% of 120 = 108, so SOFT_FLOOR at $108)
    - can_enter at NORMAL, quality 0.5 -> (True, None)
    - can_enter at SOFT_FLOOR, quality 0.90 -> (True, None) -- exceptional
    - can_enter at SOFT_FLOOR, quality 0.80 -> (False, "soft_floor_low_quality")
    - can_enter at HARD_FLOOR, quality 1.0 -> (False, "hard_floor_hit")
    - can_manage at NORMAL -> True
    - can_manage at SOFT_FLOOR -> True
    - can_manage at HARD_FLOOR -> False
    - Edge: $0 equity -> HARD_FLOOR
    - Edge: HWM $0 (not initialized) -> handle gracefully (avoid division by zero)
  </behavior>
