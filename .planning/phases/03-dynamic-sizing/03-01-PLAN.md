    Build DynamicSizer using TDD (RED -> GREEN -> REFACTOR cycle).

    **RED - Write failing tests first** in tests/unit/test_sizing.py:

    SizingConfig is a dataclass with these fields (all Decimal):
    - base_risk_pct: Decimal("1.0") -- base risk per trade as % of equity
    - max_position_pct: Decimal("10.0") -- max single position as % of equity
    - consecutive_loss_threshold: int = 3 -- reduce size after N consecutive losses
    - size_reduction_after_losses: Decimal("0.5") -- multiply size by this after consecutive losses
    - max_concurrent_positions: int = 5 -- position count limit

    DynamicSizer has:
    - __init__(config: SizingConfig) -- stores config, initializes state
    - initialize(starting_capital: Decimal) -- sets starting_capital and high_water_mark
    - calculate_position_size(current_equity: Decimal, quality_score: Decimal) -> Decimal
      - base_size = current_equity * (base_risk_pct / 100)
      - If consecutive_losses >= threshold: base_size *= size_reduction_after_losses
      - quality_multiplier = Decimal("0.5") + quality_score (maps 0.0->0.5x, 1.0->1.5x)
      - adjusted = base_size * quality_multiplier
      - Cap at max_position_pct of current_equity
      - Return quantized to 0.01
    - update_after_trade(pnl: Decimal) -- if pnl < 0: consecutive_losses += 1, else: reset to 0
    - update_high_water_mark(current_equity: Decimal) -- track peak

    Write tests for these cases (input -> expected output):
    - $100 equity, quality 0.50 -> base $1.00 * 1.0 multiplier = $1.00
    - $100 equity, quality 1.00 -> base $1.00 * 1.5 multiplier = $1.50
    - $100 equity, quality 0.00 -> base $1.00 * 0.5 multiplier = $0.50
    - $120 equity (after gains), quality 0.50 -> base $1.20 * 1.0 = $1.20 (scales with equity!)
    - $80 equity (after losses), quality 0.50 -> base $0.80 * 1.0 = $0.80 (contracts!)
    - After 3 consecutive losses, $100 equity, quality 0.50 -> $1.00 * 0.5 reduction * 1.0 quality = $0.50
    - After 3 losses then 1 win, $100 equity, quality 0.50 -> $1.00 (reset, no reduction)
    - Max position cap: $100 equity, quality 1.0 with max_position_pct=1.0 -> capped at $1.00 not $1.50
    - High water mark: initialize at $100, update to $120, update to $110 -> HWM stays $120
    - Zero equity edge case: $0 equity -> $0.00 position size

    Run tests -- they MUST fail (RED). Commit: `test(03-01): add failing tests for DynamicSizer`
