<objective>
Build the AdaptiveSizer that bridges Phase 3 DynamicSizer and Phase 4 Kelly sizing with graceful cold start handling.

Purpose: The cold start problem is critical -- Kelly needs historical edge data that doesn't exist for new tokens. AdaptiveSizer solves this by using Phase 3 DynamicSizer as fallback until per-token edge data reaches minimum threshold, then seamlessly transitions to Kelly-based sizing. No trades are ever skipped due to lack of data.

Output: Tested AdaptiveSizer that automatically selects between Phase 3 fallback and Kelly sizing based on available per-token edge data.
</objective>
