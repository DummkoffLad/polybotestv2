**Action A: Write tests and capture baselines programmatically.**

Pick ONE session file for integration testing: `data/sessions/session_20260129_191609.jsonl` (the one already used in test_dry_run_smoke.py, 234 events, proven to work). Reserve the other 5 session files for Phase 5 out-of-sample validation (per context recommendation).

Write the test file with an initially empty EXPECTED_BASELINES dict and these tests:

1. `test_session_file_exists()` - Assert SESSION_FILE.exists(). Skip with clear message if not.

2. `@pytest.mark.parametrize("strategy_name", list_strategies())`
   `test_replay_completes_without_error(strategy_name)` - Load session, create strategy, run replay. Must not raise any exception. Assert result.events_processed > 0.

3. `@pytest.mark.parametrize("strategy_name", list_strategies())`
   `test_replay_pnl_consistency(strategy_name)` - Run replay. Assert result.total_pnl == result.realized_pnl + result.unrealized_pnl (PnL accounting identity).

4. `@pytest.mark.parametrize("strategy_name", list_strategies())`
   `test_replay_nonnegative_counts(strategy_name)` - Assert buys_executed >= 0, sells_executed >= 0, skips >= 0. Assert buys_executed + sells_executed + skips == events_processed.

5. `@pytest.mark.parametrize("strategy_name", list_strategies())`
   `test_replay_deterministic(strategy_name)` - Run replay TWICE with same inputs. Assert buys, sells, skips are identical both times (determinism check).

6. `test_replay_baselines(strategy_name)` - If EXPECTED_BASELINES is populated, verify exact match. SKIP if baselines not yet populated (first run). Use `@pytest.mark.skipif(not EXPECTED_BASELINES, reason="Baselines not yet captured")`.

Run the tests once with `-v -s` to confirm they pass with empty baselines.

Then run a baseline capture: for each of the 8 strategies, run the replay and print/capture the actual buys_executed, sells_executed, and skips values.
