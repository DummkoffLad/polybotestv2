**Parameterized tests across ALL strategies** (use @pytest.mark.parametrize("strategy_name", ALL_STRATEGIES)):

1. `test_strategy_initializes(strategy_name)` - get_strategy(name), call initialize(config). Should not raise. Verify strategy.name == strategy_name.

2. `test_strategy_returns_trade_decision(strategy_name)` - Initialize, create a normal BUY event (ask=0.50, dollars=10), call on_event(). Result must be a TradeDecision instance with action in (BUY, SKIP).

3. `test_strategy_skips_extreme_low_price(strategy_name)` - Create BUY event with ask=Decimal("0.01"). All strategies must return SKIP with reason "price_extreme_low".

4. `test_strategy_skips_invalid_high_price(strategy_name)` - Create BUY event with ask=Decimal("1.00"). All strategies must return SKIP (reason may be "invalid_price" or similar).

5. `test_strategy_sell_no_position_skips(strategy_name)` - Create SELL event for a token the strategy has never bought. Must return SKIP with reason "no_position".

6. `test_strategy_buy_updates_portfolio_on_fill(strategy_name)` - Create BUY event, call on_event, if result is BUY call on_fill. Then verify strategy.portfolio has a position (shares > 0). If result is SKIP (e.g., min_shares), that's acceptable -- just verify it doesn't crash.

7. `test_strategy_get_state_returns_dict(strategy_name)` - Initialize, call get_state(). Must return a dict with "positions" key.

8. `test_strategy_on_session_end_returns_dict(strategy_name)` - Initialize, call on_session_end(). Must return a dict.

**Step 3: Add strategy-specific tests based on readings from Step 1.**

Add 1-2 targeted tests for each strategy that verify its unique differentiator. At minimum include:

9. `test_mirror_applies_size_boost()` - Initialize MirrorStrategy. Create BUY event with leader dollars=100, ask=0.50. The mirror strategy applies scale_ratio * 1.30 boost. With $100 capital, $900 leader capital, k=0.85: scale_ratio = (100/900)*0.85 = 0.09444. Scaled = 100 * 0.09444 * 1.30 = 12.28. Verify the decision dollars are in a reasonable range (between 1 and 30). Don't hardcode exact value -- just verify boost is applied by checking dollars > what you'd expect without the 1.30x.

10. `test_conservative_uses_tighter_caps()` - Initialize ConservativeMirrorStrategy. It uses 20% market cap, 18% side cap, 80% global. Verify by checking the strategy's internal constants match. Also verify it skips small leader trades below MIN_LEADER_TRADE_PCT (1%) of leader capital.

11. `test_conservative_skips_small_leader_trade()` - Initialize conservative strategy. Create event with leader dollars = Decimal("5") (which is 5/900 = 0.56% of leader capital, below 1% threshold). Should skip with "leader_trade_too_small".

12. `test_momentum_conviction_increases_sizing()` - Initialize MomentumMirrorStrategy. Feed it multiple BUY events for the same token within the conviction window. The second or third trade should have larger sizing than the first (due to conviction multiplier). Compare decision.dollars from first vs subsequent events. NOTE: Read the momentum strategy code first to understand exact conviction multiplier logic. If the momentum code doesn't expose multipliers directly, verify indirectly via dollar amounts.

13. `test_mirror_sell_with_position()` - Initialize mirror, buy some shares (create BUY event, on_fill), then create SELL event for same token. Should produce SELL decision (not skip).

14. `test_mirror_no_price_skips()` - Create event with ask=None (no price data). Should skip with "no_price".

15. `test_strategy_count_is_eight()` - Assert len(list_strategies()) == 8. This catches accidental strategy deregistration.
