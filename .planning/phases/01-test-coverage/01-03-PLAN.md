  <name>Task 1: Write risk cap enforcement unit tests</name>
  <files>tests/unit/test_risk_caps.py</files>
  <action>
Create tests/unit/test_risk_caps.py. Use MirrorStrategy as the reference implementation since it has standard caps (30% market, 26% side, 100% global, 10% reserve). Create local helpers (same pattern as test_strategies.py -- self-contained, no dependency on conftest from Plan 01).

**Local helpers:**
- `_make_trade(**kw)` - LeaderTrade factory with defaults
- `_make_prices(**kw)` - PriceSnapshot factory with defaults
- `_make_event(trade_kw=None, price_kw=None)` - MarketEvent factory
- `_make_config(**kw)` - StrategyConfig factory with $100 defaults
- `_init_strategy(config_overrides=None)` - Create and initialize a fresh MirrorStrategy with optional config overrides. Returns (strategy, config).
- `_buy_and_fill(strategy, market_id, token_id, side, ask, leader_dollars)` - Helper that creates a BUY event, calls on_event, and if BUY decision, calls on_fill. Returns the TradeDecision. This helper is critical for building up positions before testing cap enforcement.

**Per-Market Cap Tests (30% = $30 for $100 capital):**

1. `test_per_market_cap_allows_under_limit()` - Buy $20 in market_a. Should succeed (under $30 cap).

2. `test_per_market_cap_enforced_after_reaching_limit()` - Fill buys in market_a until get_market_exposure >= $28 (close to cap). Then try another buy in same market. Should either get capped to small amount or skip with "market_cap".

3. `test_per_market_cap_different_markets_independent()` - Fill $25 in market_a, then buy in market_b. Market_b buy should succeed (independent cap).

**Per-Side Cap Tests (26% = $26 for $100 capital):**

4. `test_per_side_cap_allows_under_limit()` - Buy UP side in a market for $20. Should succeed.

5. `test_per_side_cap_enforced()` - Fill UP side to near $26, then try another UP buy. Should skip "side_cap" or be capped.

6. `test_per_side_cap_opposite_sides_independent()` - Fill UP side to $25, then buy DOWN side in same market. DOWN buy should succeed (different side).

**Global Exposure Cap Tests (100% = $100 for $100 capital, but limited by reserve):**

7. `test_global_cap_enforced()` - Fill buys across multiple markets until near deployable limit (90% of $100 = $90 due to reserve). Next buy should skip "reserve" or "global_cap".

8. `test_cash_reserve_limits_deployment()` - With 10% cash reserve, only $90 is deployable. Fill to $88 deployed. Try $5 more buy. Should be capped to ~$2 or skip.

**Hourly Budget Tests:**

9. `test_hourly_budget_limits_spending()` - Set hourly_budget to $50. Fill buys until hourly_budget_used reaches $48. Next buy should be capped or result in min_order skip.

10. `test_hourly_budget_resets_on_hour_change()` - Fill buys to exhaust hourly budget. Then create an event with a timestamp in the NEXT hour. The budget should reset and the buy should succeed. To test: use a timestamp like datetime(2026, 1, 29, 13, 0, 0) for first events, then datetime(2026, 1, 29, 14, 0, 1) for the post-reset event.

**Boundary Condition Tests:**

11. `test_cap_boundary_exactly_at_limit()` - Set up exposure to exactly $30 (market cap). Next buy in same market should skip "market_cap" (room is exactly 0).

12. `test_min_order_enforcement_under_cap()` - When remaining cap room is $0.50, but 5-share minimum at ask=$0.50 needs $2.50 -- should skip "min_shares" or "min_order" since can't meet minimum.

**Multi-Cap Interaction Tests:**

13. `test_smallest_cap_wins()` - Set config with per_market=30%, per_side=10% (tighter side cap). A buy should be limited by the side cap ($10), not the market cap ($30). Verify decision dollars <= $10.

14. `test_cascading_caps_multiple_markets()` - Fill 3 different markets to various levels. Global exposure should be the sum. Verify global cap catches when individual market caps haven't fired.

**Sell-Side Tests (caps don't apply to sells):**

15. `test_sell_not_blocked_by_caps()` - Fill a position. Even with all caps maxed out, selling should work (sells reduce exposure, not increase it).

**Edge Cases:**

16. `test_zero_capital_config()` - Set starting_capital=0. Strategy should handle gracefully (skip everything, not crash).

17. `test_very_small_budget_caps_bind_immediately()` - Set starting_capital=Decimal("10"). Per-market cap = $3. First buy of a $200 leader trade should be aggressively capped.

IMPORTANT: For each test, trace through the actual MirrorStrategy._buy() code to determine the expected outcome. The caps are enforced in this order in mirror: reserve check -> budget room -> market_cap -> side_cap -> global_cap -> min_shares check. Understand this flow when predicting outcomes.

Use Decimal for ALL values. No pytest.approx. Each test is independent (fresh strategy instance).

Per phase context: If any cap enforcement test reveals a bug (e.g., cap doesn't fire when it should), document it as a critical comment with "# BUG:" prefix. Risk cap bugs that could lose real money may warrant immediate fixes per phase context, but start by documenting.
