<task type="auto">
  <name>Task 2: Write comprehensive portfolio unit tests</name>
  <files>tests/unit/test_portfolio.py</files>
  <action>
Create tests/unit/test_portfolio.py with the following test functions. Use Decimal for ALL financial values. Use exact equality with Decimal (NOT pytest.approx -- it doesn't work with Decimal). Use quantize(Decimal("0.0001")) when comparing values that go through avg_price calculation.

**Cost Basis Tests:**

1. `test_single_buy_cost_basis()` - Buy 10 shares @ 0.50. Assert cost_basis == Decimal("5.00"), shares == 10, avg_price == Decimal("0.5000")

2. `test_multiple_buys_cost_basis()` - Buy 10 @ 0.50, then 20 @ 0.60. Assert cost_basis == Decimal("17.00"), shares == 30, avg_price == Decimal("0.5667") (quantized to 0.0001)

3. `test_buy_different_tokens_independent()` - Buy token_a and token_b. Assert each position tracks independently.

**Realized PnL Tests:**

4. `test_sell_at_profit_realized_pnl()` - Buy 10 @ 0.50, sell 5 @ 0.70. Realized PnL should be 5 * (0.70 - 0.50) = 1.00. Remaining shares = 5, cost_basis = 2.50.

5. `test_sell_at_loss_realized_pnl()` - Buy 10 @ 0.60, sell 10 @ 0.40. Realized PnL should be 10 * (0.40 - 0.60) = -2.00.

6. `test_partial_sell_preserves_remaining_cost_basis()` - Buy 20 @ 0.50 (cost=10), sell 10 @ 0.60. Remaining cost_basis should be 5.00 (half), remaining shares = 10.

**Unrealized PnL Tests:**

7. `test_unrealized_pnl_at_higher_price()` - Buy 10 @ 0.50 (cost=5). Call calculate_pnl with current price 0.70. Unrealized = 10*0.70 - 5 = 2.00.

8. `test_unrealized_pnl_at_lower_price()` - Buy 10 @ 0.60 (cost=6). Call calculate_pnl with current price 0.40. Unrealized = 10*0.40 - 6 = -2.00.

**Combined PnL Tests:**

9. `test_realized_plus_unrealized_total()` - Buy 20 @ 0.50 (cost=10), sell 10 @ 0.70 (realized=2.00). Then check unrealized with remaining 10 shares at current price 0.80 = 10*0.80 - 5 = 3.00. Total = 5.00.

**Invariant Tests:**

10. `test_buy_negative_shares_raises()` - portfolio.apply_buy with shares=-5 should raise PortfolioInvariantError.

11. `test_buy_price_zero_raises()` - apply_buy with price=0 should raise PortfolioInvariantError.

12. `test_buy_price_one_raises()` - apply_buy with price=1.0 should raise PortfolioInvariantError (price must be in (0,1)).

13. `test_sell_negative_shares_raises()` - apply_sell with shares=-5 should raise PortfolioInvariantError.

14. `test_sell_more_than_owned_clamps()` - Buy 10, sell 15. Sell should clamp to 10 shares (warning logged, not error). Verify shares after = 0.

**Exposure Tests:**

15. `test_get_total_deployed()` - Buy in two different tokens, verify total_deployed == sum of cost bases.

16. `test_get_market_exposure()` - Buy two tokens in market_a, one in market_b. Verify get_market_exposure("market_a") returns only market_a cost basis.

17. `test_get_side_exposure()` - Buy UP and DOWN in same market. Verify get_side_exposure returns only the queried side.

**Edge Cases:**

18. `test_dust_cleanup_after_full_sell()` - Buy 10 shares, sell exactly 10. Verify shares == 0, cost_basis == 0, avg_price == 0 (dust cleanup at < 0.001).

19. `test_portfolio_clear()` - Buy some positions, call clear(). Verify everything is reset.

20. `test_total_bought_total_sold_tracking()` - Make several buys and sells. Verify total_bought and total_sold accumulators match.

Each test should be a standalone function using the fresh_portfolio fixture. Import make_trade/make_prices from conftest as needed but most tests just call portfolio.apply_buy/apply_sell directly.
  </action>
