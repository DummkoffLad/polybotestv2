  <action>
    1. **Update requirements.txt:**
       - Change `websockets>=12.0` to `websockets>=16.0`

    2. **Install the new version:**
       ```bash
       pip install "websockets>=16.0"
       ```

    3. **Update `src/data/ws_price.py`:**

       The current code uses the legacy API:
       ```python
       import websockets
       async with websockets.connect(self.ws_url, ping_interval=20, ping_timeout=10) as ws:
       ```

       Change to the new v16 API:
       ```python
       from websockets.asyncio.client import connect
       async with connect(self.ws_url, ping_interval=20, ping_timeout=10) as ws:
       ```

       Specific changes needed in `_ws_main()`:
       a. Replace the lazy `import websockets` inside `_ws_main()` with a top-level import:
          ```python
          from websockets.asyncio.client import connect as ws_connect
          ```
          Put this at the top of the file with other imports. Use `ws_connect` alias to avoid shadowing.

       b. Update the connection line:
          ```python
          # Old:
          async with websockets.connect(self.ws_url, ping_interval=20, ping_timeout=10) as ws:
          # New:
          async with ws_connect(self.ws_url, ping_interval=20, ping_timeout=10) as ws:
          ```

       c. Remove the try/except ImportError block around `import websockets` since v16 is now a hard requirement (not optional).

       d. The rest of the code should work as-is:
          - `ws.send()` and async iteration `async for raw in ws:` are unchanged in v16
          - `ping_interval` and `ping_timeout` parameters are still supported
          - JSON message handling is unchanged

       e. Add a graceful fallback: If websockets is not installed, log an error but don't crash. Wrap the import at module level with try/except:
          ```python
          try:
              from websockets.asyncio.client import connect as ws_connect
              HAS_WEBSOCKETS = True
          except ImportError:
              HAS_WEBSOCKETS = False
              ws_connect = None
          ```
          Then in `_ws_main()`:
          ```python
          if not HAS_WEBSOCKETS:
              logger.error("websockets>=16.0 not installed, price feed disabled")
              return
          ```

    4. **Verify the upgrade works:**
       ```bash
       python -c "import websockets; print(f'websockets {websockets.__version__}')"
       python -c "from websockets.asyncio.client import connect; print('v16 API available')"
       python -c "from src.data.ws_price import WebSocketPriceService; print('Import OK')"
       ```
