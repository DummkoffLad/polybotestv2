<feature>
  <name>ConfidenceIntervalCalculator</name>
  <files>src/statistics/confidence.py, tests/unit/test_statistics_confidence.py</files>
  <behavior>
    Bootstrap confidence intervals using scipy.stats.bootstrap:

    1. pnl_confidence_interval(pnls: List[Decimal]) -> Tuple[float, float, float]
       - Returns (mean_pnl, ci_lower, ci_upper)
       - Uses percentile bootstrap with 10000 resamples
       - Fixed seed (42) for reproducibility
       - Handles empty list: returns (0.0, 0.0, 0.0)
       - Handles single element: returns (value, value, value)

    2. win_rate_confidence_interval(pnls: List[Decimal]) -> Tuple[float, float, float]
       - Returns (win_rate, ci_lower, ci_upper) as percentages (0-100)
       - Win defined as pnl > 0
       - Same bootstrap parameters as pnl_confidence_interval

    Test cases:
    - Empty list -> (0.0, 0.0, 0.0)
    - Single element -> (value, value, value) for PnL, (0 or 100, 0 or 100, 0 or 100) for win rate
    - Known distribution: [1, 2, 3, 4, 5] -> mean=3.0, CI should be narrower than full range
    - All positive PnLs -> win rate 100%
    - Mixed PnLs -> win rate between 0-100%
    - Reproducibility: same input produces same CI (fixed seed)
  </behavior>
  <implementation>
    Use scipy.stats.bootstrap with:
    - method='percentile' (simple and robust)
    - n_resamples=10000 (industry standard)
    - confidence_level=0.95 (configurable via __init__)
    - random_state=np.random.default_rng(seed=42) for reproducibility

    Convert Decimal to float for numpy compatibility.
    Return floats for easier downstream use.
  </implementation>
</feature>

    - BASIC_RELIABILITY = 100 (basic confidence)

       - Returns dataclass with:
         - trade_count: int

         - confidence_level: str ("minimum", "basic", "high")
         - warning_message: str
         - is_adequate: bool

    2. recommend_more_data(current_count: int) -> str
       - Estimates additional sessions needed
       - Assumes ~10 trades per session (conservative)

    - 150 trades, target="basic" -> is_adequate=True
    - recommend_more_data(45) with target="basic" -> message includes "55" and "6 sessions"
  </behavior>
  <implementation>
    Simple threshold comparison with clear warning messages.
    Use dataclass for structured return.
    Warning messages include warning emoji for visibility.
  </implementation>
</feature>
