<feature>
  <name>RegimeAnalyzer</name>
  <files>src/statistics/regime.py, tests/unit/test_statistics_regime.py</files>
  <behavior>
    Session regime classification and comparison:

    @dataclass RegimeMetrics:
      - session_id: str
      - start_time: datetime
      - end_time: datetime
      - duration_hours: float
      - is_overnight: bool
      - is_daytime: bool
      - avg_price_volatility: float (avg % price change)
      - avg_spread_pct: float (optional, can be 0.0 if not provided)
      - event_count: int
      - events_per_hour: float
      - regime_label: str (e.g., "overnight_low_vol", "daytime_high_vol")

    @dataclass RegimeComparisonResult:
      - regime_a_label: str
      - regime_b_label: str
      - regime_a_pnl_mean: float
      - regime_b_pnl_mean: float
      - difference: float (b - a)
      - is_significant: bool
      - p_value: float
      - interpretation: str

    RegimeAnalyzer methods:

    1. classify_session(
        session_id: str,
        start_time: datetime,
        end_time: datetime,
        price_changes: List[float],  # % changes
        spreads: List[float] = None,  # % spreads (optional)
        event_count: int = 0
    ) -> RegimeMetrics

    Classification rules (from research):
    - Overnight: start OR end hour is in [22, 23, 0, 1, 2, 3, 4, 5] (10PM-6AM)
    - Daytime: otherwise
    - High volatility: avg(abs(price_changes)) > 5.0
    - Low volatility: avg(abs(price_changes)) <= 5.0
    - regime_label = f"{time}_{volatility}" (e.g., "overnight_low_vol")

    2. compare_regimes(
        regime_a_sessions: List[Dict],  # {session_id: str, pnls: List[Decimal]}
        regime_b_sessions: List[Dict],
        regime_a_label: str,
        regime_b_label: str
    ) -> RegimeComparisonResult

    Uses Welch's t-test (scipy.stats.ttest_ind with equal_var=False) because:
    - Regimes are independent groups (not paired)
    - Welch's handles unequal variances (robust)

    Test cases:
    - classify_session with 2AM start -> is_overnight=True
    - classify_session with 10AM start -> is_overnight=False (daytime)
    - classify_session with 8% avg volatility -> "high_vol"
    - classify_session with 2% avg volatility -> "low_vol"
    - compare_regimes with identical PnLs -> p near 1.0, not significant
    - compare_regimes with very different PnLs -> p < 0.05, significant
    - compare_regimes handles empty regime lists gracefully
    - Edge case: duration spanning overnight/daytime boundary
  </behavior>
  <implementation>
    Time-of-day classification:
    - OVERNIGHT_HOURS = {22, 23, 0, 1, 2, 3, 4, 5}
    - Check if start_time.hour OR end_time.hour is in OVERNIGHT_HOURS
    - This captures sessions that start/end during overnight period

    Volatility classification:
    - Calculate mean of absolute values: np.mean([abs(p) for p in price_changes])
    - Threshold: 5.0 (from research)

    Regime comparison:
    - Aggregate all PnLs from each regime's sessions
    - Use scipy.stats.ttest_ind(a_pnls, b_pnls, equal_var=False)
    - Return structured result with interpretation

    Handle edge cases:
    - Empty price_changes: avg_volatility = 0.0
    - Empty regime sessions: raise ValueError or return inconclusive
    - Single session per regime: still valid for t-test (but low power)
  </implementation>
</feature>
